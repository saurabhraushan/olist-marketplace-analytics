# GitHub Upload Guide

1. Create a public repository named `olist-marketplace-analytics`.
2. Upload the contents of this folder, preserving the directory structure.
3. Add the packaged Tableau workbook under `tableau/` if you want visitors to download it. Do not upload raw customer-level data unless the dataset licence and your privacy review allow it.
4. Confirm that all six screenshots render in `README.md` and that `sql/` contains the six numbered workflow files.
5. Replace the profile link with the direct workbook URL if you prefer visitors to land on the first dashboard immediately.
6. Add repository topics such as `sql`, `mysql`, `tableau`, `data-analysis`, `ecommerce` and `portfolio-project`.
7. Pin the repository on your GitHub profile.

Suggested repository description:

> End-to-end Olist e-commerce analysis using MySQL and Tableau: growth, customers, geography, products, freight, delivery, sellers and payments.
